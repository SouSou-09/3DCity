# 3DCity

GTAのようなリアルな3D都市を手続き生成するプロジェクト(Three.js + TypeScript)。

碁盤目やノイズ任せにせず、実際の都市と同じ順序で階層的に生成します:
地形 → 高速道路 → 地区 → 幹線・補助幹線 → 生活道路 → (街区・建物・装飾物)。
同じシードからは常に同じ街ができます。

## 使い方

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # 生成結果の検証
npm run stats   # 複数シードの道路統計
npm run build
```

URLパラメータ: `?seed=4`、`&view=3d`、`&layers=districts,nodes,field,raw`。

## M1 地形と道路網

| 段階 | 内容 | ファイル |
|---|---|---|
| 地形 | 海岸線(湾と岬)、蛇行する川、丘 | `src/gen/terrain.ts` |
| 地区 | 都心・旧市街・住宅地・郊外・丘陵・工業・ビーチ。地区ごとに街路の向き・間隔・曲がり方・袋小路の割合が違う | `src/gen/districts.ts` |
| 高速道路 | 海岸に沿う本線、港への支線、幹線との交差部にインターチェンジ | `src/gen/highways.ts` |
| 方向場 | 地区の向き・海岸線・川岸・等高線・高速道路を合成したテンソル場 | `src/gen/tensorField.ts` |
| 街路 | 方向場に沿った流線を幹線→補助幹線→生活道路の順に引く。川には橋を架ける | `src/gen/streamlines.ts`, `src/gen/roads.ts` |
| グラフ | 交差点で分割、鋭角・極小区間の除去、行き止まりの延長と整理、公園、孤立部分の接続、橋の切り出し | `src/gen/roadGraph.ts` |

確認用の表示は2D地図(`src/debug/mapView.ts`)と簡易3Dプレビュー(`src/view3d/cityView.ts`)。

## M2 道路アセット(テクスチャと3Dモデル)

道路を組み立てるための部品を手続き生成で用意したもの。**まだ街の地図には配置していません**(配置はM3以降)。
`npm run dev` のあと http://localhost:5173/catalog.html で全パターンを一覧・拡大表示できます
(`?tab=models|textures`、`&cat=bridge`、`&model=<id>`、`&tex=<id>`、`&dir=x,y,z&zoom=n`)。

### テクスチャ(367種)

画像ファイルは持たず、IDから毎回同じ絵を生成します。1枚ごとにアルベド・法線・AO/粗さ/金属度の3枚組(PBR)で、
大きさはメートルで定義され、路面類は継ぎ目なくタイルします。

| 分類 | 数 | 例 |
|---|---|---|
| アスファルト | 48 | 新しい/使用中/摩耗/白化、ひび・亀甲ひび・補修跡・シール材・掘り返し跡、バス/自転車レーンの着色、コンクリート舗装 |
| コンクリート | 15 | 歩道の目地違い、汚れ・ひび、側溝、乗入れ部 |
| 舗装材 | 35 | ヘリンボーン・馬踏み・市松・芋目地のブロック、板石、小舗石、点字ブロック、木道 |
| 縁石 | 10 | コンクリート、御影石、赤・黄・青・白の塗装 |
| 地面 | 12 | 芝、砂利、土、砂、マルチ |
| 構造物 | 25 | 塗装鋼(錆あり)、耐候性鋼、橋脚の型枠跡、石積み、レンガ、防護壁 |
| 区画線 | 66 | 白/黄の実線・破線・二重線、導流帯、摩耗違い |
| 横断歩道・停止線 | 45 | ゼブラ、はしご型、2本線、停止線、譲れ線、交差点内の黄色い格子 |
| 路面標示 | 73 | 矢印、STOP・BUS・SCHOOLなどの文字、自転車、車椅子、EV、速度、駐車ます |
| 蓋・汚れ | 38 | マンホール、雨水ます、ハンドホール、油じみ、タイヤ痕、補修パッチ |

- `src/assets/tex/core.ts` — タイル可能なノイズ、ラスタライザ、高さ→法線/AOの変換
- `src/assets/tex/surfaces.ts`, `markings.ts` — 素材ごとの生成器
- `src/assets/tex/registry.ts` — パターンの一覧(`TEXTURES`、`renderTexture(spec, scale)`)
- `npx tsx scripts/texPreview.ts out [idの前方一致] [scale]` — PNGに書き出す

### 3Dモデル(222種)

道路の断面(車線・駐車帯・自転車レーン・中央分離帯・側溝・縁石・植栽帯・歩道・柵)を定義し、それを直線・勾配・曲線の経路に沿って
押し出して作ります。交差点は「腕」(向き・断面・信号/一時停止/譲れ・横断歩道)の一覧から形を計算するので、任意の角度と本数に対応します。

| 分類 | 数 | 例 |
|---|---|---|
| 道路区間 | 49 | 路地〜6車線大通り、一方通行、駐車帯、自転車/バスレーン、分離帯の種類、古い路面、未舗装 |
| 高速道路・ランプ | 13 | 片側2〜4車線、分離帯違い、HOVレーン、掘割、出口の分流、ループランプ |
| 坂 | 14 | 5〜20%の勾配、坂の頂上と谷、ヘアピン、つづら折り、山腹の擁壁、ハンプ |
| カーブ | 9 | 直角〜ゆるいカーブ、S字、不規則に曲がる路地、車線シフト |
| 交差点 | 30 | 十字、T字、斜め、Y字、五差路、六差路、一方通行、信号/一時停止/譲れ |
| ロータリー・袋小路 | 10 | 3〜6本のロータリー、小型、2車線、袋小路 |
| 歩道・縁石 | 44 | 舗装材違いの歩道、縁石の種類、植栽帯、乗入れ部の切り下げ、スロープ、バルブアウト、バスベイ、安全島 |
| 橋 | 34 | 桁橋、鋼板桁、石・レンガのアーチ、上路アーチ、タイドアーチ、トラス、吊り橋、斜張橋、歩道橋 |
| 高架・立体交差 | 19 | 橋脚違いの高架、二層高架、らせんランプ、盛土/擁壁のランプ、立体交差、アンダーパス |

- `src/assets/mesh/builder.ts` — マテリアル別の三角形の集約、経路(`straight`/`grade`/`arc`/`through`…)と押し出し(`sweep`)
- `src/assets/mesh/section.ts`, `presets.ts` — 道路断面と、その一般道/高速道路のプリセット
- `src/assets/mesh/junction.ts` — 交差点とロータリー
- `src/assets/mesh/structures.ts`, `sidewalks.ts` — 橋脚・橋台・橋・高架、歩道まわりの部品
- `src/assets/mesh/registry.ts` — パターンの一覧(`MODELS`、各 `build()` が頂点・法線・UV・マテリアルIDを返す)
- `src/catalog/` — カタログ画面
